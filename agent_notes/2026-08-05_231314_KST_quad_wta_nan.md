# Quad WTA K=6 NaN under particle coupling

## Goal

Stop `Adversary · Quad WTA K=6` from painting `surprise NaN` / black canvas
within ~40s of live play, without dulling the piece.

## Verified facts

- Offline `tools/adversary_stability_probe.ts` (no advect, random field
  batches) stays finite for 3000 steps at gallery defaults — it does **not**
  catch this failure.
- Particle-coupled probe (`tools/quad_nan_probe.ts`: advect + particle-sourced
  D/G + field Adam, N=60k, drive=0.65) blew at ~4300–4750 steps before the fix.
- Live Metal Chrome reproduced at ~41s: `surprise`/`pred` → NaN, heads
  `█▁▁▁▁▁` (NaN argmin collapses to head 0), black canvas. Speed ≈ 24√2.
- Tri WTA K=6 failed the same coupled probe (~4800 steps) — not Quad-only.
- At the tip-over step, **field weights were still finite** (max ≈ 1.64). The
  adversary step itself produced nonfinite stats / adv weights / extGrads.
- Root chain: SELU pre-activations overflow → Inf·0 matmul NaNs → nonfinite
  residuals / `y` → Adam Inf/Inf → poisoned weights. HUD head-collapse is a
  *symptom* of NaN residuals, not the cause.

## Fix shipped

1. Clamp SELU pre-activation to ±80 in `train_wgsl.ts` `COMMON` and
   `advect_wgsl.ts` (shared by field + adversary fused paths).
2. Gate nonfinite raw residuals, surprise, `y`/`u`, field signals, RMS
   reductions, Adam steps (`advOpt` + field pass B), and `extGrads`.
3. Probe: `tools/quad_nan_probe.ts` (TAG/N/FIELD_LR/FINE_AFTER knobs).

## Measured after fix

- Coupled probe: 12 000 steps finite, nonzero AG/EG, heads healthy.
- Live Chrome Quad soak: **180s finite**, surprise ~1.4–1.85, heads balanced.
- `bun tools/train_wta_test.ts`: ALL FUSED WTA CHECKS PASS.

## Unresolved / next

- Guards contain blow-ups; field weight max still drifts (~2.5 at 12k steps).
  Optional follow-up: soft weight decay or a slightly lower standalone G LR.
- Parcel HMR mid-soak briefly showed a WIP `PIXEL_DISC_TILES` export error from
  the unfinished pixel-disc branch — unrelated to this NaN fix; do not confuse
  with the adversary regression.
